1. INTRODUCTION
----------------------------------------
This project applies the complete machine learning workflow to a real-world
text classification problem: detecting toxic comments in online discussions.
The work covers exploratory data analysis (EDA), data preprocessing, ensemble
model training with hyperparameter tuning, and rigorous performance evaluation.

The goal is to build a reliable binary classifier that can flag harmful or
offensive user-generated text, supporting safer online communities and content
moderation pipelines. The project uses Python with Pandas, Scikit-learn,
XGBoost, and LightGBM, following standard ML practices from raw data inspection
through model comparison and selection.


2. PROBLEM STATEMENT
----------------------------------------
Online platforms receive large volumes of user comments daily. Manual moderation
does not scale, and toxic content can harm users and degrade community quality.
The problem is formulated as a supervised binary classification task:

  • Input:  Features derived from a comment (text and metadata)
  • Output: Whether the comment is toxic (1) or non-toxic (0)

Challenges include severe class imbalance (~90% non-toxic vs. ~10% toxic),
high-dimensional text features, and the need to avoid label leakage from
related toxicity sub-labels (severe_toxic, obscene, threat, insult,
identity_hate). The objective is to maximize overall classification quality
while maintaining reasonable detection of the minority toxic class.

8. CONCLUSION
----------------------------------------
This project successfully built and evaluated an ensemble-based pipeline for
toxic comment detection on a dataset of 223,549 online comments. After EDA,
preprocessing (TF-IDF text features, leakage prevention, scaling), and
RandomizedSearchCV hyperparameter tuning, Random Forest emerged as the best
overall model with 87.24% accuracy, 87.12% F1-score, and 74.28% ROC-AUC.

Ensemble methods (Voting, Stacking) did not outperform Random Forest on
overall metrics, though Stacking improved toxic-class recall at the cost of
accuracy. The class imbalance remains the primary challenge: while non-toxic
comments are classified reliably, detecting toxic comments (F1 ~32%) requires
further work. The project demonstrates a complete ML workflow suitable for
content moderation applications, with clear paths for improvement outlined below.
